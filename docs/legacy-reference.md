# Legacy Reference (extracted before rewrite)

Captured from the deleted Angular/Konva/Express implementation. This is the source of truth for visual/feature parity in the Rust + PixiJS rewrite.

## Tile geometry

- Tile = 40×80 px, two 40×40 halves stacked vertically. Bottom half rendered rotated 180° (offset 40,40) so its pips read upside-down like a real domino.
- Face: `#FAF0E6` fill, black 1px stroke.
- Back face (flipped state): same `#FAF0E6` rect with black stroke covering the whole 40×80 tile.
- Tile name/id: `"{top}x{bottom}"` with top ≤ bottom generated by `for i in 0..=size { for j in i..=size }` → double-9 = 55 tiles, double-12 = 91, double-15 = 136.

## Other pieces

- **Center hub**: black octagon, radius 100, rotation 22.5°, with a white 50×90 rect at (-25,-40) on top (slot for the starting double). Default position (900, 250). Draggable, synced.
- **Trains**: 8 draggable markers, each the 🚂 emoji at fontSize 35. Synced (x,y only).
- **Drop areas**: circular two-tone gradient targets (outer + inner circle). Public board drop area: blue gradient (`#4a90e2`→`#357abd`, hover `#357abd`→`#2c3e50`). Local board drop area: green gradient (`#4CAF50`→`#388E3C`). Dropping a tile within the outer circle's radius transfers it between boards; tile is repositioned at the drop area center, rotation reset to 0 and un-flipped when drawn to hand.

## Interactions

- Drag any tile/train/center; on drag start tile moves to top (z).
- Click/tap: attach rotation transformer, snaps [0, 90, 180, 270], resize disabled.
- Double-click/tap: toggle flip (backFace visibility).
- **Shuffle**: for each tile on the public board: random position x ∈ [100,400), y ∈ [100,400), random rotation 0–358, flipped=true; staggered 100 ms/tile (animation nicety only).
- **Arrange hand**: grid-tidy tiles in the local board.
- Zoom: ±0.2 scale steps, min scale 0.4. Pan: drag on empty background (200 ms hold threshold in legacy; used `movementX` — broken on touch, must be fixed in rewrite).

## Legacy sync semantics (replaced by Y-CRDT)

- Envelope `{event, room, data}` over one Socket.IO `"message"` event.
- Coarse: whole-board `update`/`setup` (all tiles + center + trains) overwrote room state.
- Fine: `pieceUpdate` `{name, action: move|create|destroy, x, y, rotation, flipped}`; `destroy` = drawn to hand, `create` = played from hand.
- State blob per room: `{boardData: {tiles: [{name,x,y,rotation,flipped}], center: {x,y}, trains: [{name,x,y}]}, players: [socketIds]}` in Redis.
- Private hands were client-only and lost on refresh (rewrite: `owner` field in CRDT).
